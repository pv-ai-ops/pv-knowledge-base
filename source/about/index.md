# 关于药物警戒知识库

## 我们的使命

**药物警戒知识库 (PV Knowledge Base)** 是一个专注于**AI驱动的药物安全监测技术**的专业平台，由 **pv-ai-ops** 团队精心打造。

我们致力于：
- 📊 **技术前沿**：分享AI在药物警戒领域的最新应用
- 🔍 **框架评测**：深度对比分析主流AI框架在医药安全中的应用
- 📈 **数据可视化**：提供交互式的技术对比和分析工具
- 💡 **知识共享**：构建开放的药物安全技术社区

## 核心团队

**pv-ai-ops** 是一支专注于医药AI技术应用的专业团队，拥有：
- 丰富的药物警戒实践经验
- 深厚的AI技术背景
- 对医药行业痛点的深度理解

## 主要内容板块

### 1. AI框架对比分析
我们提供深度对比分析：
- **FastGPT vs Agno-AGI** 框架对比
- **LangGraph vs Agno-AGI** 技术分析
- 框架性能、适用场景、集成难度等多维度评估

### 2. 交互式工具
- 实时数据可视化图表
- 框架性能对比工具
- 决策支持系统

### 3. 技术文档库
- 最佳实践指南
- 技术实现方案
- 行业标准和法规解读

## 技术栈

- **静态站点**：Hexo + Next主题
- **数据可视化**：Chart.js, D3.js
- **交互体验**：Tailwind CSS, 响应式设计
- **部署**：GitHub Pages + GitHub Actions
