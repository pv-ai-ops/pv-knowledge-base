# 关于 AI 知识库

## 我们的使命

**AI知识库 (AI Knowledge Base)** 是一个面向工程实践的知识分享平台，由 **pv-ai-ops** 团队打造，内容覆盖但不限于药物警戒（PV）。

我们致力于：
- 📊 **技术前沿**：分享 AI / 大模型 / 智能体 的最新实践
- 🔍 **框架评测**：深度对比分析主流 AI 框架与方案选型
- 📈 **数据可视化**：提供交互式的技术对比和分析工具
- 💡 **知识共享**：构建开放的 AI 工程与应用社区

## 核心团队

**pv-ai-ops** 是一支专注于 AI 技术应用的团队，拥有：
- 丰富的行业落地与工程实践经验
- 深厚的AI技术背景
- 对复杂业务场景的深度理解

## 主要内容板块

### 1. AI框架与 Agent 分析
我们提供深度对比分析：
- **FastGPT vs Agno-AGI** 框架对比
- **LangGraph vs Agno-AGI** 技术分析
- 框架性能、适用场景、集成难度等多维度评估

### 2. 交互式工具
- 实时数据可视化图表
- 框架性能对比工具
- 决策支持系统

### 3. 技术文档库
- 最佳实践指南
- 技术实现方案
- 行业标准与合规要点解读

## 技术栈

- **静态站点**：Hexo + Next主题
- **数据可视化**：Chart.js, D3.js
- **交互体验**：Tailwind CSS, 响应式设计
- **部署**：GitHub Pages + GitHub Actions
